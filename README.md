# MikScrollingBattleTextOptions

Personal mirror of the MSBT options addon, split from
[brues-code/Vanilla_MikScrollingBattleText](https://github.com/brues-code/Vanilla_MikScrollingBattleText).

Auto-synced hourly from upstream via GitHub Actions
([`.github/workflows/sync.yml`](.github/workflows/sync.yml)).

## Install

```sh
cd "<your WoW>/Interface/AddOns"
git clone https://github.com/Rothiss/MikScrollingBattleTextOptions.git
```

## Update

```sh
git -C "<your WoW>/Interface/AddOns/MikScrollingBattleTextOptions" pull
```
